About the Project

Rainfall Prediction Using ML · AIML course-based project

1 · Intelligent Ensemble Learning

Linear Regression (baseline), Random Forest, Gradient Boosting and a Voting Ensemble are trained on the same chronological split and compared using MAE, RMSE and R². The best model is chosen from validation results, not assumed.

2 · Location-Aware Prediction

The location is a model input. Only locations present in the training data are supported, and latitude/longitude are used only if experiments show they help.

3 · Heavy-Rainfall Early Warning

A class-imbalance-aware classifier flags likely heavy-rainfall events. It does not predict floods: no soil, river, terrain or flood-record data is used.

Architecture

Browser (HTML/CSS/JS, Chart.js, Leaflet) → fetch() → Flask REST API → saved scikit-learn models (Joblib) + metadata.json. Models are trained once offline and only loaded by the API.

  • Frontend: vanilla JavaScript, no framework
  • Backend: Flask, pandas, NumPy, scikit-learn, SQLite for alert history
  • Explainability: permutation importance

Limitations

  • Predictions are only as good as the dataset the models were trained on.
  • Typical-value autofill uses historical averages, not live weather.
  • This is an academic demonstration, not an official forecasting service.
